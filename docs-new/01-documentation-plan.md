## Порядок создания документации

### Этап 1: Общая архитектура
1. Создать `02-architecture.md` с описанием архитектурных принципов
2. Описать структуру Monorepo
3. Документировать межсервисную коммуникацию через NATS
4. Описать управление данными

### Этап 2: Описание сервисов
1. Составить список всех сервисов
2. Для каждого сервиса создать отдельный файл в `03-services/`
3. Заполнить по шаблону:
   - Общая информация
   - Архитектура
   - База данных (таблицы)
   - HTTP API
   - NATS интеграции
   - Внешние интеграции

### Этап 3: CI/CD
1. Изучить текущие CI/CD процессы
2. Документировать pipeline
3. Описать процессы развертывания
4. Документировать миграции БД

### Этап 4: Best Practices
1. Изучить существующий код и паттерны
2. Собрать рекомендации команды
3. Документировать best practices
4. Добавить примеры кода
